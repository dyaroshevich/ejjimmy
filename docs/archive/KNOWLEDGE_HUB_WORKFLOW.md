# 📚 Инструкция: Управление Центром Знаний (Knowledge Hub)

Этот файл описывает процесс добавления новых статей, экспертных мнений и кейсов в систему TAWAN POWER.

## 🏗 Структура Системы
Центр знаний работает по технологии **RAG (Retrieval-Augmented Generation)**:
1. **Данные** хранятся в файле `data/knowledge-base.json`.
2. **ИИ-память**: Скрипт превращает текст в векторы и сохраняет в таблицу `knowledge` в Supabase.
3. **Интерфейс**: Компонент `src/components/KnowledgeGrid.tsx` запрашивает эти данные и отображает их пользователю.

---

## 🚀 Как добавить новую статью или кейс

### 1. Редактирование JSON
Откройте файл `data/knowledge-base.json` и добавьте новый объект:
```json
{
  "id": "unique-id-slug",
  "category": "Expertise", 
  "title": "Заголовок на тайском",
  "content": "Краткое описание для карточки (тайский)",
  "key_takeaway": "Главная мысль для ИИ (тайский)",
  "tags": ["Tag1", "Tag2"]
}
```
*Категории в коде:* `Expertise` (Техника), `Finance` (Финансы), `Process` (Процесс).

### 2. Синхронизация с БД
После изменения JSON нужно обновить «мозги» ИИ и базу данных. Запустите в терминале:
```bash
node scripts/load-solar-products.js
```
*Скрипт очистит старые данные и загрузит новые, создав для них векторные эмбеддинги.*

### 3. Проверка на сайте
Секция `KnowledgeGrid` на главной странице автоматически подтянет новые записи из базы данных. ИИ-чат также начнет использовать эту информацию для ответов.

## 🛠 Технические детали (для разработчика)
- **Таблица в Supabase**: `knowledge`
- **Фильтрация в UI**: Происходит по полю `metadata->type == 'article'`.
- **Эмбеддинги**: Используется модель `gemini-embedding-001`.
- **Синхронизация**: При ошибке `429 (Resource Exhausted)` нужно подождать 1-2 минуты и запустить скрипт повторно (лимиты бесплатного API Google).

## 📈 Планы на будущее (Кейсы)
Для добавления реальных кейсов (Portfolio/Cases) можно использовать тот же механизм, добавив категорию `Cases` в JSON и новый фильтр в компонент `KnowledgeGrid`.
