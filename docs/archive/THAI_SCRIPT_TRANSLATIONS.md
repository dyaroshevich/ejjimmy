## Key Thai Polite Markers Summary

| Speaker | Ending particle | When to use |
|---------|-----------------|-------------|
| Male (usual) | ครับ (kráp) | End of most sentences when speaking politely |
| Female (usual) | ค่ะ (khâ) | End of most sentences when speaking politely |
| Both genders | คะ (khâ) used for questions/requests | When asking a question or making a request |
| Softer tone | นะครับ/นะคะ (ná kráp/khâ) | When you want to soften a statement or request |

**Examples:**
- Statement: "I'll call you tomorrow" → "พรุ่งนี้จะโทรครับ" (male) / "พรุ่งนี้จะโทรค่ะ" (female)
- Question: "Are you available?" → "ว่างไหมครับ?" (male) / "ว่างไหมคะ?" (female)
- Softer: "Could you tell me?" → "ช่วยบอกได้ไหมนะครับ?" / "ช่วยบอกได้ไหมนะคะ?"

---

## Cultural Notes

1. **Never use**: กู/มัน/ตาย€™ (very rude)
2. **Avoid stating directly**: "คุณÑo not understand?" → use "ช่วยอธิบายอีกทีได้ไหม?" (Could you explain again?)
3. **Always give option**: Don't force immediate decision. "您可以 considerar แล้ว镇 tell me later."
4. **Respect hierarchy**: If customer seems older, use even more polite language (adding "ครับ/คะ" more frequently, using longer phrases)
5. **Smile in text**: Use emojis sparingly (🙏, ✅, ⚠️) but not excessive (❤️, 😂 not professional)
