# Phase 1: LINE Mini App (Главный фокус - тренд 2026)

## Концепция

Полноценное мини-приложение внутри LINE с современным дизайном (custom CSS), интеграцией с AI и полным каталогом товаров.

## Техническая архитектура

```
┌─────────────────────────────────────────────────────────────┐
│  LINE MINI APP - "Tawan Power Solar Hub"                   │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐       │
│  │ Каталог │  │ AI Чат  │  │ Заявка  │  │ Контакт │       │
│  │ Солнечные│  │Консульт.│  │ Калькулят│  │ Офис/   │       │
│  │ панели  │  │ в LINE   │  │ доходности│ │ WhatsApp│       │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘       │
└─────────────────────────────────────────────────────────────┘
```

## Основные фичи

- ✅ Custom CSS дизайн (уникальный, не как у всех)
- ✅ Интеграция с базой знаний (RAG)
- ✅ Каталог товаров с фильтрами
- ✅ Калькулятор экономии
- ✅ Форма заявки → `/api/notify-line` (уже есть)
- ✅ Custom URL: `tawanpower.line.me`

## Доступ пользователей

1. QR код на сайте
2. Ссылка из LINE OA
3. Поиск в LINE (future)
4. LINE Beacon (физический локации)

## Каналы интеграции

### Каталог товаров (в Mini App)
- Отображение solar_products из Supabase
- Фильтры: мощность, цена, тип
- Карточки товаров с изображениями
- Кнопка "Узнать цену" → форма заявки

### AI Чат (в Mini App)
- Использование существующего `/api/chat`
- Интеграция с RAG (база знаний)
- Контекст про solar в Thailand

### Форма заявки
- Те же поля что на сайте
- Отправка в Supabase + LINE уведомление
- Deep link для возврата в чат

## Типы действий

| Кнопка | Action Type | Target |
|--------|-------------|--------|

| Калькулятор | URI | Mini App / calculator |
| Контакт | URI | tel: или external |
| Заявка | URI | Mini App / form |
| Об объекте | postback | RAG query |

## Техническая реализация

1. Создать rich menu object через Messaging API
2. Загрузить image (2500x1686)
3. Set default rich menu для всех пользователей
4. Postback events для аналитики

# Phase 3: AI Chatbot (Перенос с сайта в LINE)

## Концепция

AI-консультант работающий внутри LINE, использующий тот же `/api/chat` что и на сайте.

## Архитектура

```
User → LINE → Webhook → /api/chat → RAG → Ответ
                                     ↓
                              Flex Message товары
```

## Сценарии использования

### Сценарий 1: FAQ Bot (Самый высокий ROI)
- 40-60% рутинных вопросов автоматизированы
- Примеры: "часы работы", "гарантия", "монтаж"
- Сложность: Low | ROI: Highest

### Сценарий 2: Lead Qualification Bot
- 5-7 квалификационных вопросов
- Интеграция с CRM (Supabase leads table)
- Сложность: Medium | ROI: High

### Сценарий 3: Booking Pre-Qualification
- Дата, размер системы, бюджет
- Проверка доступности или handoff человеку
- Сложность: High | ROI: Good

## Интеграция с существующей системой

- Использовать `/api/chat` (уже есть)
- Обработка webhook events от LINE
- RAG из knowledge table (уже есть)
- Flex Message для товаров (есть в line.ts)

# Phase 4: LINE Beacon (O2O)

## Концепция

Online-to-Offline воронка для офиса/шоурума в Krabi.

## Архитектура

```
┌─────────────────────────────────────────────┐
│  O2O FUNNEL (Online-to-Offline)            │
├─────────────────────────────────────────────┤
│                                             │
│  [QR/Beacon] → [Уведомление] → [Mini App]   │
│      ↓              ↓             ↓         │
│  Посетитель    "Добро пожаловать!"  Каталог │
│  офиса        Скидка 15%           Заявка   │
│                                             │
│  Trigger: Приближение к офису (Krabi)       │
│  Action:  Service Message (бесплатно!)      │
│  Goal:   Посещение → Консультация → Сделка  │
└─────────────────────────────────────────────┘
```

## Требования

1. **Офис/шоурум в Krabi** - физическая локация
2. **LINE Beacon устройство** - заказать или использовать phone
3. **Service Message** - бесплатные уведомления через LINE Mini App Notice OA

## Сценарии

| Trigger | Сообщение | Action |
|---------|-----------|--------|
| Вход в зону | "Добро пожаловать! Скидка 15% на консультацию" | Mini App |
| Повторное посещение | "С возвращением! Ваша скидка уже ждет" | Mini App |
| Рядом с офисом (вечер) | "Мы открыты до 18:00, заходите!" | Mini App |
