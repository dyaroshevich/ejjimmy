# ⚡ Vercel Power Pack: План развития Solar Krabi

План внедрения инструментов Vercel для превращения проекта в масштабируемую платформу.

## 1. Vercel OG (Built-in Next.js) - Динамический Маркетинг
*   **Статус:** Внедряем сейчас.
*   **Функция:** Генерация уникальных превью-картинок для ссылок на лету. 
*   **Зачем:** Ссылки в LINE и WhatsApp будут выглядеть как элитные карточки товаров. Привлекает внимание и повышает кликабельность.

## 2. Vercel Toolbar (@vercel/toolbar) - Командная работа
*   **Статус:** Запланировано.
*   **Функция:** Визуальный слой комментариев поверх сайта.
*   **Зачем:** Быстрый сбор фидбека от заказчиков и старших специалистов прямо на элементах интерфейса.

## 3. Vercel Edge Config (@vercel/edge-config) - Управление "на лету"
*   **Статус:** Запланировано.
*   **Функция:** Глобальный конфиг с чтением за <10мс.
*   **Зачем:** Мгновенное переключение AI-провайдеров (Gemini/Groq) без деплоя. Позволяет менять "мозги" сайта за одну секунду.

## 4. Vercel KV (Redis) - Скорость и Лимиты
*   **Статус:** Запланировано.
*   **Функция:** База данных в памяти.
*   **Зачем:** Кеширование ответов чата и ограничение количества запросов от одного пользователя (Rate Limiting).

## 5. Supabase Storage (Альтернатива Vercel Blob)
*   **Статус:** Запланировано (Рекомендуется).
*   **Функция:** Облачное хранилище файлов.
*   **Зачем:** Хранение реальных фото панелей и инверторов для каталога. Интегрировано с текущей базой данных.
