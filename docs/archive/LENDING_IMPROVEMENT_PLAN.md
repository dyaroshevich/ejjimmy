## 📋 Конкретные задачи для следующей итерации

### **1. Видео-фон для Hero секции**
```markdown
**Задача:** Создать впечатляющее видео-фоновое решение
- Варианты: дрон-съемка Краби + солнечные панели, таймлапс установки, динамичный монтаж
- Технически: overlay с текстом, оптимизация для мобильных, autoplay + mute
- Альтернатива: CSS анимация + градиенты если видео недоступно
```

### **2. Реальные кейсы**
```markdown
**Задача:** Создать раздел с реальными проектами
- Формат: Карточки с фото, описанием, результатами
- Метрики: "Экономия 12,000 THB/мес", "Окупаемость 4.5 года"
- Гео: Указывать районы Краби (Ao Nang, Klong Muang, Railay)
- CTAs: "Смотреть полный кейс", "Получить расчет для моего дома"
```

### **3. Галерея товаров с реальными фото**
```markdown
**Задача:** Заменить заглушки на реальные изображения
- Фото оборудования: крупным планом, в установке, детали
- Фото установок: разные ракурсы, разные типы зданий
- Фото команды: процесс работы, общение с клиентами
- Технические фото: схемы, спецификации, сравнения
```

### **4. Админка и лид-сбор**
```markdown
**Задача:** Создать полноценную систему управления лидами
- Dashboard: Статистика лидов, конверсии, активность
- Лид-менеджмент: Статусы (Новый, В работе, Закрыт), назначение менеджеров
- Аналитика: Источники лидов, эффективность каналов
- Уведомления: Email, SMS, push-уведомления
- Отчеты: Ежедневные, еженедельные, ежемесячные
```

### **2. База данных для лидов:**
```sql
-- Таблица лидов
CREATE TABLE leads (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  project_type VARCHAR(100),
  budget_range VARCHAR(50),
  message TEXT,
  status VARCHAR(50) DEFAULT 'new',
  assigned_to UUID,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Таблица уведомлений
CREATE TABLE notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  lead_id UUID REFERENCES leads(id),
  type VARCHAR(50),
  message TEXT,
  sent_at TIMESTAMP DEFAULT NOW(),
  status VARCHAR(20) DEFAULT 'pending'
);
```
