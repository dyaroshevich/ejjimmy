## Carbon Calculation Methodology

**Standard:** Use GHG Protocol (widely accepted)

**Formula:**
```
CO2 avoided (tons/year) = System production (kWh/year) × Grid emissions factor (kg CO2/kWh)
```

**Thailand grid emissions factor:**
- ~0.5 kg CO2/kWh ( mixed: natural gas, coal, renewables )
- Source: Thailand's Climate Change Master Plan

**Example 10kW system:**
- Production: ~13,000 kWh/year (Phuket)
- CO2 avoided: 13,000 × 0.5 = 6,500 kg = **6.5 tons CO2/year**
- Over 25 years: 162.5 tons CO2

**Equivalent:**
- 162 trees planted
- 36 cars taken off road for 1 year

## Carbon Credits (Revenue Opportunity)

**Voluntary carbon market:**
- Verify carbon savings (through third-party standard: Gold Standard, Verra)
- Register project
- Issue carbon credits (1 credit = 1 ton CO2)
- Sell credits to corporations ($5-20/ton)

**Process:**
1. Register solar installation as "activity" under standard
2. Monitor actual production (data from inverter)
3. Calculate actual CO2 avoided (vs grid average)
4. Periodic verification (annual)
5. Issue credits
6. Sell on marketplace

**Revenue potential:**
- 10kW system → ~6.5 credits/year → $32-130/year
- For 100 systems → $3,200-13,000/year passive

**Complexity:** Moderate — need third-party verifier, fees (~$1-2/credit)
