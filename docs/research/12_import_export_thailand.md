## Import Duties on Solar Equipment

**ASEAN Free Trade Area (AFTA):**
- Thailand-China: Not ASEAN, so no AFTA benefits
- ASEAN countries (Vietnam, Malaysia, Indonesia): potential 0% duty if Certificate of Origin
- China → Thailand: Most solar equipment faces import duties

**Typical duties (HS Code 8541.40):**
- Solar panels: 0-5%? (Check Customs)
- Inverters: 5-10%
- Mounting structures: 5-10%

**Additional taxes:**
- VAT on import: 7%
- Excise: maybe none for solar

**Total landed cost:**
- Equipment price FOB China: $X
- + Freight: $Y
- + Insurance: $Z
- + Import duty: (X+Y+Z) × duty%
- + VAT: (X+Y+Z+duty) × 7%
- = Total CIF Thailand

**Example:**
- $100,000 solar panels FOB
- Freight $2,000
- Duty 3% → $3,060
- VAT 7% → ($102,060) × 7% = $7,144
- Total: $112,204 → 12% overhead vs FOB

## Shipping Logistics

**From China (Shanghai/Ningbo) to Bangkok:**
- **LCL (Less than Container Load):** per cubic meter or per pallet
- **FCL (Full Container 20' or 40'):** if buying bulk
- **Transit time:** 7-14 days sea + 2-3 days customs
- **Cost:** $500-1500 per CBM LCL, or $2,500-4,000 for 20' container

**To Phuket:**
- From Bangkok port to Phuket by truck (1-2 days)
- Cost: ฿20,000-50,000 per truck

## Customs Clearance

**Required documents:**
- Commercial Invoice
- Packing List
- Bill of Lading
- Certificate of Origin ( if claiming duty preference )
- Import License (maybe not for solar)
- Insurance certificate

**Process:**
1. Ship arrives, file customs declaration
2. Customs inspection (random)
3. Pay duties/VAT
4. Release goods

**Timeline:** 2-5 business days if docs in order

**Customs broker:** Hire one (cost ~฿5,000-10,000/shipment) to handle

## Direct Import vs Local Distributor

### Local Distributor (current):
- **Pros:** No import hassle, quick delivery (in stock), warranty handled by them, can buy small quantities
- **Cons:** Markup 20-40%, payment terms limited, stockouts possible

### Direct Import:
- **Pros:** Lower cost (15-30% savings), control over sourcing, potentially better payment terms with factory
- **Cons:** Import duties paperwork, need customs broker, larger MOQ (minimum 1 pallet/20' container), longer lead time (4-6 weeks), warranty claims need to go through factory directly

**Break-even analysis:**
- If annual spend >฿5M with distributor, direct import might save ฿750k-1.5M/year
- But need staff time to manage importing (~½ FTE)
