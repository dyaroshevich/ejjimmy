# Solar price benchmark — South Thailand, 2026-10-23

Внутренний исследовательский артефакт (не публикуется в `public/`). Все цены в THB, дата исследования 2026-10-23.

| Файл | Что внутри |
|---|---|
| `benchmark.csv` | 35 SKU: рынок low/median/high, наш прайс, Δ%, вердикт (MARKET ±15% / OVERPRICED / UNDERPRICED / NO_DATA), число источников, южных источников, notes |
| `quotes.csv` | 164 строки — по одной на публичную цену: URL, цитата, дата, tier A–D, признак `included_in_median` (дубли, выбросы, старые посты помечены `no` + причина) |
| `summary.md` | 1 страница, 7 разделов |
| `REPORT.md` | Полный отчёт: методика, все 35 SKU таблицами, C&I, пробелы, чек-лист обновления |
| `gaps.csv` | 14 подтверждённых пробелов: нет публичной цены, модельный разрыв, нет пакета, единица не сопоставима |

## Как пересобрать

```bash
python build.py      # -> benchmark.csv, quotes.csv
python make_gaps.py  # -> gaps.csv
```

`quotes_data.py` — исходные данные (список `QUOTES`), `bom_quotes.py` — компоненты, встречающиеся только внутри BOM (в бенчмарк не входят), `build.py` — нормализация НДС (×1.07 при `vat="no"`), медианы, вердикты.
