## Executive Summary

**Критически важно:** Без правильных permits установка solar illegal, может быть демонтирована, штрафы.

**Main permits needed:**
1. **MEA/PEA Interconnection Agreement** — позволяет продавать излишки в сеть (net metering)
2. **Building Permit** — если конструкция на крыше требует инженерного одобрения
3. **Fire Department Approval** — для больших систем (>10kW)
4. **Electrical Work Permit** — work by licensed electrician

**Timeline:** 2-6 недель total
**Cost:** ฿5,000-20,000 (в зависимости от региона)
**Who handles?** Typically we (installer) manage all для customer (включено в pricing)

### 1. MEA/PEA Interconnection Process

**Что это:** Соглашение с электростанцией, которое позволяет:
- Подключиться к распределительной сети
- Продавать излишки энергии (net metering)
- Получить bi-directional meter ( bidirectional meter for net metering)

#### Requirements:
- [ ] Completed application form (MEA/PEA)
- [ ] System design drawings (single line diagram, layout)
- [ ] Equipment specifications (panel datasheets, inverter certs)
- [ ] Proof of ownership or consent from property owner
- [ ] Installation company license/foreign business license
- [ ] Insurance certificate (liability)
- [ ] Electrical contractor license (Electrician with proper certification)
- [ ] Structural engineer report (если крыша требует проверки)

#### Process:

```
Day 0: Submit application + documents + fee (฿5,000?)
Day 3-7: MEA reviews documents
Day 7-14: Site inspection (MEA engineer comes, checks roof, panel location, existing panel)
Day 14-21: Approval issued OR revisions requested
Day 21-28: Sign PPA (Power Purchase Agreement) — 25 years typically
Day 28-35: MEA installs new meter ( bidirectional )
Day 35: System can be commissioned (отключить старый счетчик, включить новый)
```

**Timeline reality:** 4-6 weeks minimum

#### Fees:
- Application fee: ฿5,000?
- Connection fee: ฿10,000-50,000 (depends on system size)
- Inspection fee: included?
- New meter cost: ฿20,000-50,000 (MEA installs)

**Total:** ~฿35,000-100,000

#### Net Metering Details:
- **Ratio:** 1:1? или 1:0.8? (разные тарифы)
- **Term:** 25 years (fixed rate)
- **Excess credits:** carried forward month-to-month, expire annually?
- **Other:** Must maintain system in good condition, insurance

## 📊 Permit Timeline Gantt (Typical)

```
Week 1:
├── Day 1-2: Prepare application package (design, specs, docs)
├── Day 3: Submit to MEA + pay fees
└── Day 4: Apply for building permit (parallel)

Week 2:
├── MEA reviews docs
├── Building permit review
└── Schedule MEA site inspection

Week 3:
├── MEA site inspection
├── MEA decision
└── If revisions: address (adds 1 week)

Week 4:
├── Sign PPA
├── Pay connection fee
└── Schedule meter installation

Week 5:
├── MEA installs meter
├── Electrical final inspection
└── Building permit approval received

Week 6:
└── Commissioning (can turn on system)
```

**Total:** 4-6 недель (if no revisions)

1. **Document the permit process thoroughly** — create checklist, timeline, document pack template
2. **Build relationship with local MEA/PEA office** — visit, introduce company, ask about requirements
3. **Pre-qualify projects:** Before quoting, assess permit difficulty (roof type, location)

```

→ Install system → Schedule final inspection → Commissioning → Register warranty
```
