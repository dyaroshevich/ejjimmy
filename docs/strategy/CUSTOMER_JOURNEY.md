**Приоритет:** P1
**Дата создания:** 12 June 2026

## 📌 Зачем

Карта клиента от первого касания до after-sales. Показывает где теряем, где болит, где можно ускорить.

---

## 🗺️ Journey Map

### Этап 1: Осведомленность (Awareness)

| Параметр | Значение |
|----------|----------|
| **Каналы** | Google Search, Facebook/Instagram, LINE, рекомендации, Google Maps |
| **Контент** | Блог (11 статей), Google Business Profile, соцсети |
| **Действия клиента** | Ищет "солнечные панели Краби", читает статьи, смотрит отзывы |
| **Точки касания** | tawanpower.vercel.app, Google Maps, LINE |
| **Боль** | "Сколько стоит? Это реально выгодно?" |
| **Метрика** | Трафик, CTR из поиска, количество запросов |

**Блайнд спот:** Нет трекинга откуда приходят клиенты. UTM-метки не настроены.

---

### Этап 2: Интерес (Interest)

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Заходит на сайт, смотрит каталог, читает кейсы |
| **Контент** | Каталог товаров, блог, FAQ |
| **Точки касания** | Главная, каталог, страницы статей |
| **Боль** | "Есть ли подходит для моего дома? Какой бюджет?" |
| **Метрика** | Время на сайте, глубина просмотра, bounce rate |

**Блайнд спот:** Нет калькулятора окупаемости на сайте. Нет видео-контента (обзоры, монтаж).

---

### Этап 3: Рассмотрение (Consideration)

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Задаёт вопрос в чате, звонит, пишет в LINE |
| **Контент** | AI-чат (квалификация), консультация |
| **Точки касания** | /chat, LINE, телефон |
| **Боль** | "Хочу точную цену для моего случая" |
| **Метрика** | Количество чатов, конверсия чат → лид |

**Блайнд спот:** Нет каталога с ценами на сайте. Клиент не может self-qualify.

---

### Этап 4: Запрос (Inquiry)

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Оставляет заявку, заполняет форму |
| **Контент** | Форма заявки, квалификация через чат |
| **Точки касания** | /chat (квалификация), /api/notify-line |
| **Боль** | "Сколько ждать ответа?" |
| **Метрика** | Количество заявок, время ответа |

**Узкое место:** Заявка уходит в LINE — нет трекинга статуса. Нет автоматического подтверждения.

---

### Этап 5: Site Survey

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Ждёт визита инженера |
| **Действия команды** | Инжeнер выезжает, замеряет, фотографирует |
| **Точки касания** | Телефон, WhatsApp/LINE для фото |
| **Боль** | "Когда приедут? Что нужно подготовить?" |
| **Метрика** | Время от заявки до визита, % состоявшихся визитов |

**Блайнд спот:** Нет автоматического напоминания клиенту перед визитом. Нет чеклиста для инженера.

---

### Этап 6: Коммерческое предложение (Proposal)

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Получает КП, сравнивает, спрашивает |
| **Действия команды** | Генерация PDF (Breezy Premium), отправка |
| **Точки касания** | PDF-предложение, LINE/WhatsApp |
| **Боль** | "Почему так дорого? Что входит?" |
| **Метрика** | Конверсия визит → КП, время генерации PDF |

**Узкое место:** PDF генерация хрупкая (4 баг-репорта). Нет шаблона с объяснениемbenefit.

---

### Этап 7: Договор (Contract)

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Принимает решение, подписывает |
| **Действия команды** | Отправка договора, получение оплаты |
| **Точки касания** | Договор (PDF), оплата |
| **Боль** | "Можно ли рассрочку? Что если не понравится?" |
| **Метрика** | Конверсия КП → договор, средний чек |

**Блайнд спот:** Нет договора в шаблонах. Нет интеграции с платёжной системой.

---

### Этап 8: Монтаж (Installation)

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Ждёт, контролирует, принимает |
| **Действия команды** | Монтаж, тестирование, сдача |
| **Точки касания** | Монтажная бригада, акт приёмки |
| **Боль** | "Сколько дней? Будет ли шум?" |
| **Метрика** | Время монтажа, % без задержек |

**Блайнд спот:** Нет трекинга прогресса монтажа для клиента. Нет фото-отчёта.

---

### Этап 9: After-Sales

| Параметр | Значение |
|----------|----------|
| **Действия клиента** | Мониторит производительность, обращается по гарантии |
| **Действия команды** | Обслуживание, гарантийные обязательства |
| **Точки касания** | Телефон, LINE, email |
| **Боль** | "Как контролировать выработку? Что если поломка?" |
| **Метрика** | NPS, количество обращений, повторные продажи |

**Блайнд спот:** Нет мониторинга выработки. Нет программы лояльности. Нет запроса отзывов.

---

## 📊 Сводная таблица

| Этап | Конверсия (оценка) | Главная боль | Действие |
|------|-------------------|--------------|----------|
| Awareness → Interest | ~15% | Нет цен на сайте | Добавить калькулятор |
| Interest → Consideration | ~30% | Нет видео | Снять 2-3 видео |
| Consideration → Inquiry | ~20% | Долгий ответ | Авто-подтверждение |
| Inquiry → Site Survey | ~60% | Нет напоминания | Авто-напоминание |
| Site Survey → Proposal | ~80% | Хрупкий PDF | Стабилизировать |
| Proposal → Contract | ~40% | Нет рассрочки | Интеграция с банком |
| Contract → Installation | ~90% | Нет трекинга | Dashboard для клиента |
| Installation → After-Sales | ~95% | Нет мониторинга | HEMS интеграция |
