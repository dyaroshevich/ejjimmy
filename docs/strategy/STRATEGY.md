# 🚀 Strategy: Solar Revenue Engine (v2.0)

## 1. Executive Summary
**Tawan Power** трансформируется из простого AI-чата в **Solar Revenue Engine**. Это комплексная система, которая использует ИИ как инструмент доверия и квалификации, чтобы превращать анонимный трафик в реальные контракты на установку солнечных систем в Краби.

**Главный сдвиг:** Мы не продаем "разговор с роботом". Мы даем **бесплатный слой консультации**, который помогает пользователю разобраться в теме и мягко подводит его к контакту с инженером.

---

## 2. Unified UX Strategy (The "Seamless Shell")
Мы отказываемся от разделения на "Сайт" и "Чат" как разные страницы. Мы строим единую среду:

### A. Поверхность: Консультационный Лендинг
*   Работает как полноценная витрина: преимущества, пакеты, доверие.
*   Обеспечивает SEO и контекст.
*   **Consultation Bar:** Стик-панель внизу экрана с полем ввода ("Спросите о системе для дома...").

### B. Слой: Immersive Chat (Full-screen)
*   **Trigger:** Как только пользователь нажимает на поле ввода или Quick Action, чат плавно раскрывается на весь экран.
*   **Experience:** Полноценное погружение в диалог без отвлекающих факторов лендинга.
*   **State:** Чат сохраняет состояние при сворачивании. Пользователь может вернуться на лендинг (кнопка "Назад/Закрыть"), проверить информацию в блоках и снова вернуться в чат.

### C. Почему это работает:
1.  **Zero Friction:** Нет перехода между страницами.
2.  **Immersive Logic:** Чат — это не "виджет сбоку", а полноценный интерфейс консультации.
3.  **Mobile First:** Идеально для LINE Browser — один стабильный layout.

## 3. Revenue-Driven Funnel
Наша формула: **Traffic → Value → Trust → Contact → Handoff → Deal**

1.  **Value (Польза):** Бесплатный расчет, сравнение оборудования, ответы на FAQ.
2.  **Trust (Доверие):** Профессиональный дизайн, локальные данные по Краби, упоминание тайских инженеров.
3.  **Contact (Захват):** Прогрессивный сбор данных. Не просим телефон сразу. Сначала даем расчет (Instant Estimate), затем предлагаем: "Сохранить в LINE" или "Обсудить проект".
4.  **Handoff (Передача):** Автоматическая генерация Lead Summary (сегмент, чек за свет, объект) и передача в ручную обработку (Ты или подрядчик).

## 4. Segmentation Strategy
Система разделяет мир на две части с разным UX:

| Характеристика | Residential (Дом/Вилла) | Commercial (Бизнес/Отель) |
| :--- | :--- | :--- |
| **Главный мотив** | Экономия на счетах и комфорт | ROI, окупаемость и OPEX |
| **Ключевой CTA** | "Рассчитать экономию за 60 сек" | "Технико-экономический отчет" |
| **Мягкий шаг** | "Забронировать бесплатный замер" | "Связаться с инженером проекта" |

---

## 5. Technical Pillars (LINE-Ready)
*   **Layout:** App Shell через CSS Grid (Header, Scrollable Body, Input).
*   **Stability:** Использование `visualViewport` API для предотвращения прыжков интерфейса при открытии клавиатуры.
*   **Identity:** `session_id` в localStorage для бесшовного продолжения диалога. Уникальная ссылка (share link) создается только по запросу.

## 6. Phase-by-Phase Roadmap
*   **Phase 1 (Current):** Единый лендинг с иммерсивным чатом и базовой сегментацией.
