# 📋 План реализации: Интеграция Каталога Солнечных Систем, RAG и Улучшение Админок

**Цель:** Добавить каталог солнечных систем, интегрировать его для RAG-функциональности в AI Chat, и синхронизировать управление данными между Админкой и Супер Админкой.

## 🔍 Исходные данные
- Файл `twproducts.txt` содержит структурированные данные о солнечных пакетах и продуктах
- Существующая архитектура: Next.js, Tailwind CSS, Supabase, Groq/Gemini AI
- Есть рабочие админки: `/admin` и `/admin/super`
- Процесс деплоя уже отработан (см. session-ses_3146.md)

## 🎯 Варианты реализации

### Вариант 1: Полная реализация (выбран для выполнения)
Последовательная реализация всех фаз из плана с акцентом на качество и полную интеграцию.

### Вариант 2: Упрощенный MVP
Минимальные изменения для быстрой проверки концепции:
- Преобразовать данные из twproducts.txt в JSON
- Простая страница отображения продуктов в админке

### Вариант 3: Только RAG интеграция
Фокус только на улучшение AI чата:
- API эндпоинт для поиска по продуктам
- Интеграция в существующий чат
- Без изменений в админке управления каталогом

### Фаза 2: Интеграция RAG (Retrieval-Augmented Generation)
**Описание:** Научим AI Chat использовать каталог продуктов для ответов на вопросы.

#### Задача 2.1: Исследование RAG-подходов
- **Описание:** Изучить оптимальный подход для работы с каталогом товаров.
- **Варианты:**
  - Поиск по ключевым словам в базе данных (Supabase) - рекомендуется для MVP
  - Векторные представления (embeddings) для семантического поиска - для будущего расширения
- **Дейтие:** Анализ и выбор подхода
- **Верификация:** Выбран наиболее подходящий подход для MVP (текстовый поиск в Supabase)

#### Задача 2.2: Разработка модуля получения данных (Retriever)
- **Описание:** Создать функцию для поиска релевантных товаров в Supabase по запросу пользователя.
- **Дейтие:** Реализация поиска по названию, бренду, типу, мощности
- **Пример функции:**
```typescript
async function searchSolarProducts(query: string): Promise<SolarProduct[]> {
  const searchTerms = query.toLowerCase().split(' ');
  let query = supabase.from('solar_products').select('*');
  
  // Фильтрация по тексту в названии и описании
  searchTerms.forEach(term => {
    query = query.or(`name.ilike.%${term}%,description.ilike.%${term}%,brand.ilike.%${term}%`);
  });
  
  const { data, error } = await query.limit(10);
  return data || [];
}
```
- **Верификация:** Функция корректно возвращает данные для разных запросов

#### Задача 2.3: Интеграция RAG в AI Chat
- **Описание:** Модифицировать промпты для AI Chat, чтобы он мог использовать данные от Retriever.
- **Дейтие:** Обновление системы промптинга
- **Пример промпта:**
  "Ты AI-консультант Tawan Power по солнечным системам. Используй следующую информацию о доступных продуктах и пакетах: [данные из Retriever], чтобы дать точный и персонализированный ответ на вопрос пользователя: [вопрос пользователя]. Если информация о продуктах неполная, попроси уточнения."
- **Верификация:** AI Chat начал отвечать, основываясь на данных каталога
