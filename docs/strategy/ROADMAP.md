# 🗺️ Tawan Power: Roadmap v1.2

## Видение
Трансформация Solar Krabi в **Tawan Power** — элитный сервис консультаций по солнечной энергии в Краби. Чат — не просто игрушка, а экспертный помощник, ведущий к реальному контакту с инженером.

## Этапы развития (Milestones)

### 1. Фундамент и Бренд (P0) — **ЗАВЕРШЕНО ✅**
- [x] Смена названия на Tawan Power.
- [x] Исправление стабильности интерфейса для LINE Browser (App Shell Grid).
- [x] Полная реструктуризация лендинга: переход от "AI Chat" к "Consultation Hub".
- [x] Сегментация на первом экране: Home vs Business.
- [x] Устранение русского языка во всем интерфейсе (замена на Тайский/Английский).

### 2. Внутренняя CRM и Сбор Лидов (P1) — **В ПРОЦЕССЕ ⚙️**
- [x] "Chat-native" CTA: кнопки выбора сегмента в первом сообщении.
- [x] Улучшенные карточки результатов (Result Cards).
- [x] **Автоматическое сохранение**: Кнопки в результатах теперь сохраняют данные в базу (Supabase).
- [x] **Уход от LINE на первом этапе**: Замена внешних ссылок на внутренние действия (Consult Engineer).
- [ ] Оживление админки: детальная страница лида с реальными данными из базы.

### 3. Оптимизация Воронки (P2)
- [ ] Формы сбора контактов (Имя, Телефон) внутри чата при сохранении.
- [ ] Управление статусом лида прямо из админки.
- [ ] Трекинг нажатий на ключевые кнопки для аналитики.
