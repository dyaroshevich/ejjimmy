# 🚀 Стратегический план развития TAWAN POWER

## 1. Актуальное состояние (Audited)
- **Витрина**: Интерактивная сетка товаров с фильтрами, Lightbox и Modal характеристик.
- **AI-консультант**: Работает через RAG (Supabase), понимает контекст товаров.
- **Медиа-система**: Конвейер автоматической оптимизации (WebP, бренды, проекты).

## 2. Планы развития (Product Roadmap)

### A. Фронтенд (Лендинг)
- [ ] **Витрина проектов (Showcase)**: Реализация блока с реализованными проектами для социального доказательства (сортировка по типам: отели, виллы, заводы).
- [ ] **Интерактивный калькулятор**: Интеграция `solarCalculator.ts` в визуальный виджет, чтобы пользователь видел экономию "в реальном времени" до обращения к чату.
- [ ] **Отзывы клиентов**: Блок с видео-отзывами или фото довольных клиентов с их объектами.

### B. Чат (SolarChat)
- [ ] **Контекстное обучение**: Обучить AI "перехватывать" лиды (если клиент спрашивает цену, AI должен предлагать LeadForm).
- [ ] **Мультимодальность**: Возможность прикрепления клиентом фото крыши в чат для анализа (Vision AI).
- [ ] **Интеграция LINE**: Кнопка "Связаться в LINE" прямо из чата для тех, кто хочет перейти в мессенджер.

### C. Админка
- [ ] **Визуальный загрузчик**: Панель в админке для загрузки фото товаров (вместо загрузки через папки).
- [ ] **Аналитика лидов**: Дашборд с графиком поступления заявок и статусами (Новый -> Связались -> Закрыто).
- [ ] **Редактор знаний**: Интерфейс для правки FAQ, не трогая SQL/JSON файлы.

---

## 📅 Очередность (Приоритеты)
1. **Витрина проектов**: Это даст самый быстрый прирост доверия (соц. доказательство).
2. **Админка (Аналитика лидов)**: Чтобы понимать, откуда приходят клиенты.
3. **Умная форма в чате**: Конверсия лидов в базу данных.
4. **Интеграция LINE**: Для удобства общения.
