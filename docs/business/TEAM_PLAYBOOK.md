## 📋 Roles & Responsibilities

### Founder/Developer

**Ответственность:**
- Архитектура продукта
- Маркетинговая стратегия
- Финансы
- Ключевые решения

**Не делать:**
- Монтаж (нанять бригаду)
- Content (delegate)

---

### Sales Engineer (будущее)

**Ответственность:**
- Обработка лидов из LINE/CRM
- Квалификация клиентов
- Site survey (замеры, фото)
- Подготовка КП (PDF)
- Сопровождение до договора

**Тригеры для входа:**
1. Новый лид в Supabase (status = 'new')
2. Сообщение в LINE группы
3. Звонок на номер компании

**Чек-лист site survey:**
- [ ] Фото крыши (4 ракурса)
- [ ] Замер площади
- [ ] Определение ориентации (Север/Юг)
- [ ] Проверка электрического щита
- [ ] Фото для КП

---

### Installer (будущее)

**Ответственность:**
- Монтаж систем
- Тестирование
- Сдача объекта
- Гарантийное обслуживание

**Чек-лист монтажа:**
- [ ] Получить ТЗ и КП
- [ ] Проверить наличие оборудования
- [ ] Выполнить монтаж по схеме
- [ ] Протестировать систему
- [ ] Заполнить акт приёмки
- [ ] Сфотографировать результат

---

### Content Creator (будущее)

**Ответственность:**
- Блог статьи (русский + тайский)
- Соцсети (Facebook, Instagram)
- LINE контент
- Видео (обзоры, монтаж)

**Контент-план:**
- 2 статьи/мес для блога
- 3 поста/мес для соцсетей
- 1 видео/мес
