# План: Интеграция Каталога Солнечных Систем, RAG и Улучшение Админок

**Цель:** Добавить каталог солнечных систем, интегрировать его для RAG-функциональности в AI Chat, и синхронизировать управление данными между Админкой и Супер Админкой.

**Текущий контекст:**
*   Проект на Next.js, Tailwind CSS.
*   Supabase для базы данных.
*   AI Chat использует Groq/Gemini.
*   Админка (`/admin`) и Супер Админка (`/admin/super`) существуют.
*   Frontend сайта (`/` и `/chat`) работает.

---

## Фаза 1: Определение Структуры Данных и Загрузка Каталога

**Описание:** На этом этапе мы определим, как будут выглядеть данные о солнечных системах, и подготовим механизм их загрузки в базу данных.

*   **Задача 1.1: Определение Схемы Каталога Продуктов**
    *   **Описание:** Определить структуру JSON-файлов для описания товаров (солнечные панели, инверторы и т.д.).
    *   **Пример структуры (предположение):**
        ```json
        [
          {
            "id": "unique-product-id-1",
            "name": "Jinko Tiger Neo 575W",
            "brand": "Jinko Solar",
            "model": "JKM575N-72HL4-V",
            "type": "panel", // 'panel', 'inverter', 'battery', 'mounting'
            "price_thb": 4900,
            "specifications": {
              "power_watts": 575,
              "efficiency_percent": 22.5,
              "dimensions_m": "2.384m x 1.134m x 35mm",
              "weight_kg": 26.5,
              "warranty_years": 25
            },
            "image_url": "/images/products/jinko-tiger-neo.jpg",
            "description": "Высокоэффективная солнечная панель N-Type...",
            "created_at": "2024-07-01T10:00:00Z",
            "updated_at": "2024-07-01T10:00:00Z"
          }
        ]
        ```
    *   **Действие:** Пользователь должен предоставить финальную структуру или подтвердить эту.
    *   **Верификация:** Структура данных финализирована.

*   **Задача 1.2: Подготовка JSON-файлов с данными**
    *   **Описание:** На основе структуры данных создать начальный набор JSON-файлов с информацией о 10+ продуктах (как упоминал пользователь).
    *   **Действие:** Пользователь создает JSON-файлы.
    *   **Верификация:** JSON-файлы готовы.

*   **Задача 1.3: Проектирование Схемы Базы Данных (Supabase)**
    *   **Описание:** Создать новую таблицу (или несколько таблиц, если нужно) в Supabase для хранения данных о солнечных продуктах.
    *   **Таблица `solar_products` (пример):**
        *   `id` (UUID, PK)
        *   `name` (TEXT)
        *   `brand` (TEXT)
        *   `model` (TEXT)
        *   `type` (TEXT)
        *   `price_thb` (INTEGER)
        *   `specifications` (JSONB) - для хранения объекта с параметрами
        *   `image_url` (TEXT)
        *   `description` (TEXT)
        *   `created_at` (TIMESTAMPTZ)
        *   `updated_at` (TIMESTAMPTZ)
    *   **Действие:** Создать миграцию Supabase (`[timestamp]_create_solar_products_table.sql`).
    *   **Верификация:** Миграция создана.

*   **Задача 1.4: Создание скрипта для загрузки данных**
    *   **Описание:** Написать скрипт (например, на Node.js), который будет считывать JSON-файлы и загружать данные в новую таблицу Supabase.
    *   **Действие:** Разработка скрипта.
    *   **Верификация:** Скрипт успешно загружает данные в Supabase.

## Фаза 2: Интеграция RAG (Retrieval-Augmented Generation)

**Описание:** На этом этапе мы научим AI Chat использовать каталог продуктов для ответов на вопросы.

*   **Задача 2.1: Исследование RAG-подходов**
    *   **Описание:** Изучить, как лучше всего реализовать RAG для работы с каталогом товаров. Варианты:
        *   Поиск по ключевым словам в базе данных (Supabase).
        *   Использование векторных представлений (embeddings) для семантического поиска (если потребуется).
    *   **Действие:** Анализ документации Gemini/Groq SDK, Supabase, и доступных библиотек.
    *   **Верификация:** Выбран наиболее подходящий подход для MVP.

*   **Задача 2.2: Разработка модуля получения данных (Retriever)**
    *   **Описание:** Создать функцию, которая принимает запрос пользователя, ищет релевантные товары в базе данных Supabase и возвращает их описание.
    *   **Действие:** Реализация поиска по названию, бренду, типу, спецификациям.
    *   **Верификация:** Функция корректно возвращает данные для разных запросов.

*   **Задача 2.3: Интеграция RAG в AI Chat**
    *   **Описание:** Модифицировать промпты для AI Chat, чтобы он мог использовать данные, полученные от Retriever.
    *   **Действие:** Обновление системы промптинга.
    *   **Пример промпта:** "Ты AI-консультант по солнечным системам. Используй следующую информацию о продуктах: [данные из Retriever], чтобы ответить на вопрос пользователя: [вопрос пользователя]."
    *   **Верификация:** AI Chat начал отвечать, основываясь на данных каталога (например, "Панель Jinko Tiger Neo 575W имеет эффективность 22.5% и стоит ฿4,900.").
