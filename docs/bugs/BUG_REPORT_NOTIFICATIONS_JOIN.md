# 🐛 BUG REPORT: NOTIFY-001

## **Status: IDENTIFIED / FIXING**

### **1. Описание (Summary)**
Ошибка `could not find relationship` при попытке отправить уведомление. Система не может выполнить JOIN таблиц `push_subscriptions` и `user_notification_settings` напрямую, так как между ними нет прямой связи (Foreign Key).

### **2. Технические детали**
*   **Локация:** `src/app/api/notify-line/route.ts`
*   **Ошибка:** PostgREST Error (Supabase)
*   **Причина:** В коде используется запрос:
    ```typescript
    .from('push_subscriptions')
    .select('*, settings:user_notification_settings(*)')
    ```
    Supabase ожидает наличие внешнего ключа (FK) между этими таблицами для такого синтаксиса. В нашей схеме обе таблицы ссылаются на `auth.users`, но не друг на друга.

### **3. Воздействие (Impact)**
Система уведомлений полностью неработоспособна. Любой вызов API (включая тесты) возвращает 500 ошибку.

### **4. План исправления (Remediation)**
1.  Разделить запрос на два независимых получения данных: отдельно подписки, отдельно настройки.
2.  Объединить данные в коде (JS Mapping) по полю `user_id`.
3.  Оптимизировать производительность, чтобы не делать лишних запросов в цикле.
