# SEO Knowledge Base System — Tawan Power

## 🎯 Система управления SEO базой знаний

### Принципы организации:
1. **Не в один документ** - это создаст хаос и медленную загрузку
2. **Структурированное хранение** - по категориям и приоритетам
3. **Версионирование** - отслеживание изменений и обновлений
4. **Кросс-ссылки** - связь между связанными материалами
5. **Легкий поиск** - понятная иерархия и naming convention

## 📄 Naming Convention

### Формат файлов:
```
[тип]-[тема]-[подтема].[расширение]
Примеры:
- keyword-residential-krabi.csv
- content-cornerstone-solar-guide.md
- technical-schema-local-business.md
- competitor-analysis-matrix.xlsx
```

### Версионирование:
```
[базовое-имя]-v[номер-версии].[расширение]
Примеры:
- seo-roadmap-v2.md
- keyword-tracking-v3.xlsx
```

### Даты:
```
[тип]-[тема]-[гггг-мм-дд].[расширение]
Примеры:
- research-market-2026-05-18.pdf
- analysis-competitors-2026-05-18.xlsx
```

## 🛠️ Система управления версиями

### Git для SEO базы (если используется Git):
```
SEO-KNOWLEDGE-BASE/
├── .gitignore
├── README.md
├── .gitattributes
└── docs/
    └── [структура выше]
```

### Версионирование документов:
1. **Основная версия** - всегда актуальная
2. **Архив версий** - для важных изменений
3. **История изменений** - в каждом файле

### Шаблон заголовка для документов:
```markdown
---
title: "[Заголовок]"
description: "[Краткое описание]"
category: "[категория]"
tags: ["тег1", "тег2", "тег3"]
version: "1.0"
last_updated: "2026-05-18"
author: "[автор]"
---

# [Заголовок]

[Содержание]
```

## 📊 Интеграция с инструментами

### Для NotebookLM:
1. Создайте отдельную папку `notebooklm-inputs/`
2. Копируйте актуальные документы для анализа
3. Используйте структуру по категориям

### Для SEO инструментов:
1. Экспортируйте данные в соответствующие форматы
2. Храните шаблоны для импорта
3. Ведите историю изменений

### Для аналитики:
1. Используйте централизованные дашборды
2. Настройте автоматическую отчетность
3. Храните сырые данные и аналитику отдельно

## 🚀 Практическая реализация

### Шаг 1: Создайте структуру папок
```bash
mkdir SEO-KNOWLEDGE-BASE
cd SEO-KNOWLEDGE-BASE
mkdir -p 01-CORE-STRATEGY 02-KEYWORD-RESEARCH ...
```

### Шаг 2: Настройте базовые файлы
- Создайте README.md
- Настройте .gitignore
- Создайте шаблоны документов

### Шаг 3: Начните заполнять
- Перенесите существующие документы
- Создайте новые по структуре
- Настройте систему версий

### Шаг 4: Настройте поиск
- Создайте индексы
- Настройте кросс-ссылки
- Настройте инструменты поиска

## 💡 Best Practices

### Что делать:
- Регулярно обновлять документы
- Использовать понятные названия
- Создавать резервные копии
- Делиться актуальной информацией

### Чего избегать:
- Хранить все в одном файле
- Использовать сложные вложенности
- Забывать о версионировании
- Нерегулярно обновлять систему
