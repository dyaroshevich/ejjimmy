# План Наполнения Контентом и Стратегия RAG (Solar Krabi)

Этот документ описывает стратегию поиска, создания и хранения контента для сайта Solar Krabi. Цель — обеспечить AI-агента и сайт качественными данными для продаж.

## 1. Техническая Стратегия Хранения (Storage)

Эффективное хранение медиа для быстрой загрузки сайта и доступа AI.

### 1.1. Supabase Storage (Основное хранилище)
Мы создадим два публичных "бакета" (buckets) в Supabase:
*   **`products`**:
    *   **Назначение:** Фотографии товаров на белом/прозрачном фоне.
    *   **Формат:** WebP или оптимизированный PNG (до 200 КБ).
    *   **Пример:** Фото солнечной панели Jinko 575W, инвертора Huawei.
*   **`marketing`**:
    *   **Назначение:** Баннеры для сайта, PDF-брошюры (лид-магниты), реальные фото установок.
    *   **Формат:** JPG/WebP (баннеры), PDF (документы).
    *   **Пример:** "Счастливая семья в Краби под солнечными панелями", "PDF: Гайд по экономии 2024".

### 1.2. Видео-контент
*   **YouTube / Vimeo (Embed):**
    *   **Назначение:** Тяжелые видео (обзоры систем, отзывы клиентов, процесс монтажа).
    *   **Почему:** Бесплатный хостинг, отличный плеер, не нагружает наш сервер.
    *   **Реализация:** Вставляем `<iframe>` на сайт.
*   **Фоновые видео (Hero Section):**
    *   **Назначение:** Короткие зацикленные видео (3-5 сек) для атмосферы.
    *   **Хранение:** Supabase Storage (строго до 2-3 МБ, без звука).

## 2. Стратегия Наполнения Каталога (MVP: 15-20 позиций)

Не нужно добавлять всё подряд. Начинаем с "Золотого стандарта" продаж.

### 2.1. Готовые Комплекты (Solar Packages) — 4 позиции
Самый популярный продукт для частных клиентов.
1.  **3 kW Starter System** (Для счетов 2,000 - 3,500 THB/мес).
2.  **5 kW Best Seller** (Для счетов 4,000 - 7,000 THB/мес).
3.  **10 kW Large Home/Biz** (Для больших домов и офисов).
4.  **Hybrid System (с батареей)** (Полная автономия / резервное питание).

### 2.2. Солнечные Панели (Panels) — 3-4 топовых бренда
Фокус на Tier-1 производителях (надежность 25 лет).
*   **Jinko Solar** (Tiger Neo N-type 575W+).
*   **Longi Solar** (Hi-MO 6).
*   **Trina Solar** (Vertex S+).

### 2.3. Инверторы (Inverters) — 3 бренда
"Мозг" солнечной системы.
*   **Huawei** (Премиум, умный, популярный в Таиланде).
*   **Growatt** (Надежный "рабочий класс").
*   **Enphase Microinverters** (Опционально: для сложных крыш).

### 2.4. Лид-магниты (Lead Magnets)
Бесплатные материалы в обмен на контакты.
*   **PDF:** "Solar Savings Guide for Krabi 2024" (Как сэкономить на электричестве).
*   **PDF:** "Maintenance Checklist" (Чек-лист обслуживания панелей в тропиках).

## 3. Источники Контента (Sourcing)

Где брать качественные материалы.

### 3.1. Официальные Сайты (Datasheets)
*   **Что брать:** Фото продуктов на белом фоне, PDF спецификации, логотипы брендов.
*   **Плюс:** Высокое качество, доверие клиентов.

### 3.2. AI Генерация (Nano Banana / Midjourney)
*   **Что создавать:**
    *   Уникальные баннеры ("Футуристичный эко-дом в джунглях Краби").
    *   Иконки для сайта (преимущества, шаги работы).
    *   Схематичные изображения ("Как работает Net Metering").
*   **Плюс:** Уникальность, нет проблем с авторскими правами.

### 3.3. Реальные Фото (User Generated Content)
*   **Что нужно:**
    *   Фото монтажников в фирменной одежде.
    *   Фото готовых объектов в Краби (вид с дрона).
    *   Фото щитков и инверторов на стене.
*   **Плюс:** Критически важно для доверия (Social Proof).

## 4. План Действий (Action Plan)

1.  **Настройка Хранилища:**
    *   Создать Buckets в Supabase: `products`, `marketing`.
    *   Настроить политики доступа (Public Read).

2.  **Генерация и Сбор Контента:**
    *   Сгенерировать описания товаров (AI) на тайском/английском.
    *   Найти фото для 15 MVP товаров.
    *   Создать/сгенерировать 2-3 баннера для главной.

3.  **Заполнение Базы Данных:**
    *   Загрузить товары в таблицу `solar_products`.
    *   Убедиться, что AI-чат "видит" эти товары через RAG.

4.  **Интеграция на Сайте:**
    *   Отобразить товары в разделе `/products` (или в чате).
    *   Добавить скачивание PDF-брошюр.
