# 📸 Руководство по управлению медиа-контентом

Этот воркфлоу позволяет автоматически подготавливать изображения для сайта и обучать AI-чат «видеть» товары.

## 🛠 Быстрый цикл обновления (3 шага)

### 1. Добавление файлов
Просто скопируйте любые изображения (JPG, PNG) в папку соответствующего товара в директории:
`media-source/[категория]/[id-товара]/`
*Подсказка: Не нужно ничего переименовывать. Скрипт сам выберет главную картинку.*

### 2. Оптимизация для веба
Выполните команду в терминале:
```bash
node scripts/optimize-media.js
```
*Что произойдет: Картинки сожмутся в WebP, создадутся галереи и обновятся ссылки в базе данных товаров.*

### 3. Синхронизация с AI (RAG)
Чтобы чат начал показывать новые картинки, обновите его «память»:
```bash
node scripts/load-solar-products.js
```

## 💡 Особенности системы
- **Smart Main Image**: Первая картинка в папке по алфавиту автоматически становится главной.
- **Auto-Gallery**: Если в папке больше одного фото, остальные автоматически попадают в галерею товара.
- **Placeholder**: Если в папке нет фото, сайт автоматически покажет брендированную заглушку Solar Energy Krabi.
