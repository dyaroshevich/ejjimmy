# План: Интеграция LIFF с LINE

## 1. Цель
Интегрировать полученный LIFF ID в приложение Tawan Power, настроить инициализацию LIFF SDK и обеспечить корректную работу как "Virtual MINI App" внутри LINE.

## 2. Ключевые файлы и контекст
*   **LIFF ID:** `2010020881-koR53fSr`
*   **Endpoint URL:** `https://tawanpower.vercel.app/` (по нашей договоренности, открываем главную страницу)
*   **LIFF App Settings:**
    *   Size: `Full`
    *   Module mode: Enabled (скрывает кнопку действия)
    *   Scopes: `openid`, `profile`, `chat_message.write`
    *   Add friend option: `On (normal)`
*   **Файлы для модификации:**
    *   `.env.local` (или другой файл конфигурации): для хранения `NEXT_PUBLIC_LINE_LIFF_ID`.
    *   `src/hooks/useLineBrowser.ts` (или `src/app/layout.tsx`): для инициализации LIFF SDK.
    *   `LINE_STRATEGY_AND_LOGIC.md`: для документирования завершения этого этапа.

## 3. Шаги реализации

### Шаг 1: Настройка LINE Developers Console (для подтверждения)
*   **Действие:** Убедиться, что LIFF-приложение в LINE Developers Console настроено согласно предыдущим договоренностям:
    *   Endpoint URL: `https://tawanpower.vercel.app/`
    *   Size: `Full`
    *   Module mode: Enabled
    *   Scopes: `openid`, `profile`, `chat_message.write`
    *   Add friend option: `On (normal)`
*   **Верификация:** Настройки LIFF-приложения соответствуют плану.

### Шаг 2: Добавление LIFF ID в переменные окружения
*   **Действие:** Добавить строку `NEXT_PUBLIC_LINE_LIFF_ID=2010020881-koR53fSr` в файл `.env.local`.
*   **Верификация:** Переменная окружения успешно добавлена.

### Шаг 3: Инициализация LIFF SDK
*   **Действие:** Модифицировать `src/hooks/useLineBrowser.ts` (или `src/app/layout.tsx` для глобальной инициализации) для добавления вызова `liff.init()` с использованием `process.env.NEXT_PUBLIC_LINE_LIFF_ID`.
    *   Инициализацию следует выполнять только при обнаружении, что приложение запущено внутри LINE (`liff.isInClient()`).
    *   Добавить обработку ошибок инициализации.
*   **Верификация:** LIFF SDK инициализируется корректно при запуске приложения в браузере LINE.

### Шаг 4: Обновление документации
*   **Действие:** Добавить в `LINE_STRATEGY_AND_LOGIC.md` информацию о том, что LIFF ID получен и интеграция LIFF SDK началась.
*   **Верификация:** Документ отражает текущий статус.

## 4. Верификация
*   Развернуть приложение локально или на тестовом сервере.
*   Открыть LIFF-приложение через LINE (либо сканированием QR-кода, либо по прямой ссылке, если она доступна).
*   Проверить, что LIFF успешно инициализировался.
*   Проверить, что `liff.getProfile()` возвращает корректные данные пользователя (если возможно без полного запуска).
*   Проверить, что UI адаптируется (скрывается хедер/футер, если это реализовано на этом этапе).
