# 📋 План проверки локализации (Thai Language Audit)

Цель: Обеспечить идеальное отображение тайского текста, отсутствие "кракозябр" (mojibake) и корректность использования шрифтов/символов на всех страницах.

## 📅 Чек-лист проверки

### 1. Лендинг (Landing Page)
- [ ] Проверить все заголовки (особенно в блоке `#segments` и `#knowledge`).
- [ ] Проверить кнопки и CTA ("เริ่มประเมินฟรี", "ติดต่อวิศวกร").
- [ ] Убедиться, что в `ProductGrid` категории отображаются корректно.
- [ ] Проверить футер на наличие корректных тайских символов.

### 2. Чат (SolarChat)
- [ ] Проверить системный промпт: корректно ли он генерирует ответы на тайском.
- [ ] Проверить UI-элементы чата: заголовок, плейсхолдеры ввода, индикатор "กำลังพิมพ์…".
- [ ] Проверить отображение названий товаров (которые приходят из базы данных).

### 3. Админка (Admin Panel)
- [ ] Проверить заголовки таблиц заявок (Leads).
- [ ] Проверить формы редактирования товаров (ввод и отображение названий на тайском).
- [ ] Проверить сообщения об успешном сохранении/обновлении.

---

## 🛠 Технический воркфлоу (Thai-Interpreter)
1. **Кодировка**: Все файлы с тайским текстом должны быть сохранены в `UTF-8`.
2. **Анализ**: Использовать `thai-interpreter` для проверки текста на "сломанные" символы.
3. **Фиксация**: Если обнаружены искажения (моджибаке), перезаписывать файлы с принудительной кодировкой `utf8`.
